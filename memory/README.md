# بنية مجلد الذاكرة — جولة v0.1.63 (بند 14، عقد ع13)

مخزن ذاكرة بميزانية، تديره وحدة `lib/memory_store.py`:

| الملف | الغرض |
|---|---|
| `MEMORY.md` | الذاكرة الرئيسية؛ تُحمَّل أول 200 سطر / 24KB فقط |
| `<topic>.md` | ملاحظات موضوع واحد (مثال: `queue.md`) |
| `archive.md` | يُكتب **قبل** أي إعادة كتابة لـ `MEMORY.md` |
| `log/YYYY-MM-DD.md` | سجل يومي (ملاحظة لكل يوم) |
| `threads/<id>.md` | ملاحظات تشغيل/محادثة واحدة |
| `README.md` | هذا الملف (توثيق البنية حتى لا يبقى المجلد فارغًا) |

## القواعد

- **ميزانية التحميل:** أول 200 سطر / 24KB من `MEMORY.md`.
- **الاستدعاء قبل كل دور:** ≤4 ملاحظات + ≤4 مقاطع، ≤6,000 حرف.
- **تنقيح:** بيانات الاعتماد تُستبدل بـ `«redacted N chars»`
  قبل الكتابة على القرص — فلا سرّ يصل إلى القرص أبدًا.
- **الكتابة:** ذرية وبصلاحيات 0600.
- **انتهاء الصلاحية:** علامة `· until YYYY-MM-DD` في نهاية
  الإدخال؛ والمنتهي لا يُستدعى.
- **فهرس المواضيع:** ≤40 موضوعًا / 2,000 حرف.
- **سقف الإدخال:** 1,000 حرف / 20 سطرًا لكل إدخال.
