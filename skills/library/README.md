# مكتبة المهارات المتعلمة — جولة v0.1.63 (بند 25)

مهارات يتعلّمها الاستوديو من محادثاته الطويلة وتُراجَع بعد
N خطوات أدوات (`skillReviewSteps` 3–100) عبر `lib/skill_review.py`.

## البنية

- كل مهارة مجلد باسمه فيه ملف `SKILL.md` واحد
  (مثال: `fix-mlt-render/SKILL.md`).
- ملف `README.md` هذا يوثّق البنية حتى لا يبقى المجلد فارغًا.

## أوضاع المشاركة (`shareLearnedSkills` في المزايا)

| الوضع | المعنى |
|---|---|
| `off` (الافتراضي) | لا تُشارك مهارات متعلمة في المكتبة |
| `ask` | المراجعة تقترح مهارات وتنتظر سؤال المستخدم |
| `auto` | المراجعة تكتب المهارة في المكتبة تلقائيًا |

## إلغاء الاشتراك

مهارات عامل معيّن تُستبعد بملف `library-opt-out.json` في مجلد
العامل (قائمة أسماء مهارات). ملف موجود لكنه غير مقروء أو ليس
قائمة أسماء = يحتفظ العامل بكل شيء ويُسجَّل ذلك مرة واحدة.
