# أمثلة — Example commands and expected output

أمثلة أوامر مع المخرجات المتوقعة — **نصية فقط، بلا ملفات فيديو**.
شغّل الأوامر بنفسك من مجلد `studio/` وقارن مخرجاتك بما هنا؛ اختلاف
الأوقات والمسارات والمعرّفات طبيعي.

| الملف | ماذا يوضح |
|---|---|
| [`demo-run.md`](demo-run.md) | `run --demo` — أول فيديو تجريبي، والفحص بعده |
| [`publish-dry-run.md`](publish-dry-run.md) | `publish --dry-run` — حمولة النشر قبل أي نشر حقيقي |

> ملحوظة: هذه مخرجات توضيحية من تشغيلات موثّقة (الإصدار 0.1.40)؛
> الأرقام الدقيقة (الأزمنة، الأحجام، المعرّفات) تختلف من تشغيل لآخر.
> لا تُستخدم هذه الملفات كبديل عن `docs/getting-started.md`.
