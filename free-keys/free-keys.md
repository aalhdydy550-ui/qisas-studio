# مفاتيح API المجانية للاستوديو — الكتالوج

آخر تحقق: 2026-11-21. كل المفاتيح هنا من **الفئات المجانية الرسمية** فقط،
وتأتي من تسجيل المستخدم نفسه في كل مزود (بريد إلكتروني/هاتف) — لا يوجد
أي مصدر مفاتيح مشتركة أو مسروقة أو مولّدات مفاتيح في هذا النظام، ولا
يُستخدم أي منها أبدًا.

## القاعدة الذهبية

- المفتاح يُحفظ في ملف واحد فقط: `~/workspace/studio/free-keys/.env`
  بصلاحيات `600` (عبر `setup-key.py`)، ولا يُكتب أبدًا في `config.yaml`
  (اتفاق الاستوديو: لا مفاتيح في ملفات الإعدادات) ولا في الشات ولا في
  الذاكرة ولا في أي ملف آخر.
- التسجيل في كل مزود خطوة يقوم بها المستخدم بنفسه (~دقيقتان لكل مزود)؛
  الأدوات هنا تُدخل المفتاح وتختبره وتوصّله فقط.
- لا تُنشئ حسابات نيابة عن المستخدم، ولا تستخدم أي موقع "مفاتيح مجانية"
  من طرف ثالث.

## الحالة الآن (تحقق بـ `python3 free-keys.py`)

| المزود | الاستخدام في الاستوديو | متغير البيئة | الحالة |
|---|---|---|---|
| Gemini | كتابة النصوص والهوك والكابشن (موجود) | — (موصل custom.gemini) | **مربوط أصلًا** |
| DuckDuckGo AI (ddgw) | بديل مجاني بلا مفتاح عبر OmniRoute | — (بلا مفتاح) | **شغال** |
| Groq | LLM سريع للهوك والكابشن والسيناريو | `GROQ_API_KEY` | غير مضبوط |
| OpenRouter | LLM مجاني (`openrouter/free`) للهوك والكابشن | `OPENROUTER_API_KEY` | غير مضبوط |
| HuggingFace | تنزيل النماذج + Inference Providers | `HF_TOKEN` | غير مضبوط |
| Pexels | فيديوهات/صور جاهزة للفيديوهات الطويلة | `PEXELS_API_KEY` | **الإصدار متوقف مؤقتًا** |
| Pollinations | توليد صور (مصغرات/مشاهد) | `POLLINATIONS_API_KEY` | غير مضبوط |
| FreeLLMAPI | موجّه موصى به (كتالوج فقط — غير مثبّت) | — | غير مثبّت |

## 1. Groq — LLM سريع (مجاني) ✅ متحقق

- **الاستخدام:** كتابة الهوك والكابشن والسيناريو بدل Gemini عند الحاجة،
  وسرعة استجابة عالية (مئات التوكنات في الثانية).
- **الفئة المجانية (تحققت 2026-11-21):** حساب مجاني بلا بطاقة ائتمانية.
  الموديلات المجانية الحالية: `openai/gpt-oss-120b` و`openai/gpt-oss-20b`
  — ‏30 طلب/دقيقة، 1,000 طلب/يوم، 8,000 توكن/دقيقة، 200,000 توكن/يوم.
  ملحوظة: موديلات Llama لم تعد في الفئة المجانية (صارت Enterprise).
  ميزة إضافية مجانية: تحويل الصوت لنص Whisper (`whisper-large-v3`)،
  وتحويل النص لصوت عربي (`canopylabs/orpheus-arabic-saudi`).
- **التسجيل:** https://console.groq.com — سجّل بالبريد أو جوجل أو GitHub،
  ثم من صفحة API Keys (https://console.groq.com/keys) اضغط
  «Create API Key» وانسخ المفتاح فورًا (يظهر مرة واحدة، يبدأ بـ `gsk_`).
- **أين يذهب المفتاح:** `GROQ_API_KEY` في `free-keys/.env` عبر
  `python3 setup-key.py --provider groq`.
- **الاختبار:** `python3 setup-key.py --provider groq --test`
  (استدعاء خفيف: قائمة الموديلات، بلا استهلاك توكنات).

## 2. OpenRouter — LLM مجاني (`:free`) ✅ متحقق

- **الاستخدام:** LLM مجاني للهوك والكابشن، مع موجّه `openrouter/free`
  الذي يختار موديلًا مجانيًا متاحًا تلقائيًا (قائمة الموديلات المجانية
  تتغير باستمرار، فلا تُثبَّت أسماء موديلات في الكود).
- **الفئة المجانية (تحققت 2026-11-21):** حساب مجاني بلا بطاقة.
  الموديلات المنتهية بـ `:free` سعرها 0 دولار: **20 طلب/دقيقة و50
  طلب/يوم** (ترتفع إلى 1,000 طلب/يوم بعد شراء 10 دولارات رصيد مدى
  الحياة — اختياري مدفوع، غير مطلوب للاستخدام المجاني).
- **التسجيل:** https://openrouter.ai — سجّل بالبريد أو GitHub، ثم من
  صفحة API Keys أنشئ مفتاحًا (يبدأ بـ `sk-or-v1-`).
  قائمة الموديلات المجانية الحالية: https://openrouter.ai/collections/free-models
- **أين يذهب المفتاح:** `OPENROUTER_API_KEY` في `free-keys/.env` عبر
  `python3 setup-key.py --provider openrouter`.
- **الاختبار:** `python3 setup-key.py --provider openrouter --test`
  (استدعاء خفيف: `GET /api/v1/key` يعرض حد الطلبات اليومية).

## 3. HuggingFace — تنزيل نماذج + استدلال ✅ متحقق

- **الاستخدام:** تنزيل أوزان النماذج (مثل LivePortrait وSadTalker) بلا
  حدود ضغط، واستدعاء نماذج عبر Inference Providers عند الحاجة.
- **الفئة المجانية (تحققت 2026-11-21):** حساب مجاني بلا بطاقة.
  التوكن مجاني (نوع fine-grained، يبدأ بـ `hf_`)، وينتهي تلقائيًا بعد
  سنة من عدم الاستخدام. الحساب المجاني يشمل رصيدًا شهريًا صغيرًا
  للاستدلال عبر Inference Providers ومساحات CPU مجانية.
- **التسجيل:** https://huggingface.co/settings/tokens — سجّل حسابًا،
  ثم «New token» بنوع fine-grained (يُنصح بصلاحية القراءة فقط للتنزيل).
- **أين يذهب المفتاح:** `HF_TOKEN` في `free-keys/.env` عبر
  `python3 setup-key.py --provider huggingface`.
- **الاختبار:** `python3 setup-key.py --provider huggingface --test`
  (استدعاء خفيف: `GET /api/whoami`).

## 4. Pexels — فيديوهات وصور جاهزة ⚠️ الإصدار متوقف مؤقتًا

- **الاستخدام:** فيديوهات وصور جاهزة (stock) للفيديوهات الطويلة
  وMoneyPrinterTurbo — بديل مجاني لمقاطع Veo المدفوعة.
- **الفئة المجانية:** مفتاح مجاني فوري، 200 طلب/ساعة و20,000 طلب/شهر.
- **⚠️ تحذير مهم (تحقق مباشر من صفحة المساعدة الرسمية 2026-11-21):**
  «New API key issuance is currently paused» — إصدار المفاتيح الجديدة
  **متوقف مؤقتًا** من Pexels نفسها. لا يوجد التفاف مشروع حول هذا؛
  جرّب التسجيل لاحقًا من نفس الرابط، وإن عاد الإصدار أضف المفتاح بنفس
  الأداة. المصدر: https://help.pexels.com/hc/en-us/articles/900004904026-How-do-I-get-an-API-key
- **التسجيل (عند عودة الإصدار):** https://www.pexels.com/api —
  أنشئ حسابًا ثم اطلب المفتاح من صفحة API.
- **أين يذهب المفتاح:** `PEXELS_API_KEY` في `free-keys/.env` عبر
  `python3 setup-key.py --provider pexels`.
- **الاختبار:** `python3 setup-key.py --provider pexels --test`
  (بحث واحد بنتيجة واحدة).

## 5. Pollinations — توليد صور ⚠️ لم يعد مجانيًا بلا حدود

- **الاستخدام:** توليد صور (مصغرات، مشاهد توضيحية) عبر API متوافق
  مع OpenAI على `https://gen.pollinations.ai/v1`.
- **الفئة المجانية (تحققت 2026-11-21 — النموذج تغيّر):** لم تعد
  Pollinations خدمة مجانية مجهولة بلا حدود كما في الشروحات القديمة.
  الآن يلزم مفتاح `sk_`، والاستهلاك بعملة Pollen (1 Pollen ≈ 1 دولار،
  مدفوعة مسبقًا). الجزء المجاني هو **Quest Pollen**: نحو 3 Pollen
  تُكتسب من مهام إعداد في الحساب (إنشاء أول مفتاح، تجربة كل نوع
  موديل...) بلا بطاقة — تكفي لتجربة محدودة، لا لخط إنتاج يومي.
  ملحوظة: هذا يفسّر فشل المسار بلا مفتاح في OmniRoute 3.8.54.
- **التسجيل:** https://enter.pollinations.ai — سجّل بـ GitHub أو
  جوجل، أكمل مهام Quest Pollen، ثم أنشئ مفتاح `sk_` من لوحة التحكم.
- **أين يذهب المفتاح:** `POLLINATIONS_API_KEY` في `free-keys/.env`
  عبر `python3 setup-key.py --provider pollinations`.
- **الاختبار:** `python3 setup-key.py --provider pollinations --test`
  (استدعاء خفيف: قائمة الموديلات).

## 7. FreeLLMAPI — موجّه موصى به (كتالوج فقط — غير مثبّت)

- **ما هو:** مشروع مفتوح المصدر بترخيص MIT يجمع مفاتيحك المجانية من
  مزودين كثيرين (Google وGroq وMistral وOpenRouter وCerebras و
  Cloudflare وHuggingFace وغيرهم) وراء نقطة واحدة متوافقة مع OpenAI،
  مع تخزين مشفر للمفاتيح.
  الرابط: https://github.com/tashfeenahmed/freellmapi
- **ملحوظة مهمة:** المفاتيح تأتي من تسجيل المستخدم نفسه في كل مزود
  (كما في هذا الكتالوج) — FreeLLMAPI لا يوفّر مفاتيح، بل يوحّد
  استخدام مفاتيحك أنت.
- **الحالة:** إضافة للكتالوج فقط — **لم يُثبَّت** ولم تُنفَّذ أي خطوة
  تثبيت له. التثبيت لاحقًا بقرار من المستخدم إن أراد توحيد المفاتيح
  المجانية في نقطة واحدة بدل إضافة كل مزود لـ OmniRoute على حدة.

## ربط المفاتيح بـ OmniRoute (بعد التسجيل)

ملف التعريفات الجاهز: `omniroute-combos.json` (في هذا المجلد) —
**لا يُطبَّق قبل إضافة المفاتيح**. الخطوات بعد إضافة أي مفتاح:

```bash
# 1) أضف اتصال المزود في OmniRoute (المفتاح من stdin — لا يظهر في السجل)
source ~/workspace/studio/free-keys/.env
printf '%s' "$GROQ_API_KEY" | omniroute providers add groq --credential-stdin

# 2) تحقق من الاتصال
omniroute providers test groq

# 3) أنشئ الكومبو من ملف التعريفات (كومبو واحد في كل مرة — راجع الملف)
python3 -c "import json; d=json.load(open('omniroute-combos.json')); print(json.dumps(d['combos'][0]))" > /tmp/groq-combo.json
omniroute api combos post-api-combos --body @/tmp/groq-combo.json

# 4) اختبر الكومبو قبل الاعتماد عليه
omniroute chat -m groq-free "مرحبًا"
```

ملحوظة: معرّفات الموديلات في ملف الكومبو تتبع نمط
`<provider>/<upstream-model>` (مثل `groq/openai/gpt-oss-120b`)،
وتُتحقق من كتالوج OmniRoute/لوحة التحكم وقت التطبيق، لأن قائمة
الموديلات الكاملة لا تظهر إلا بعد إضافة اتصال المزود.

## قواعد الأمان (إلزامية)

1. لا يُطبع المفتاح ولا يُسجَّل ولا يُرسل في الشات أبدًا — الأدوات
   تعرض اسم المزود والطول فقط.
2. ملف `.env` بصلاحيات `600` فقط، ولا يُرفع على git ولا يُشارك.
3. إن تسرّب مفتاح: احذفه من لوحة تحكم المزود فورًا وأنشئ بديلًا،
   ثم حدّثه عبر `setup-key.py` (يستبدل السطر نفسه ولا يكرره).
4. مفاتيح الاختبار الوهمية تُحذف من `.env` فور انتهاء الاختبار.
